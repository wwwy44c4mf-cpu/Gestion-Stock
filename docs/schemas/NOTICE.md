# Schéma de validation tiers

`openapi-3.1.schema.json` est le schéma officiel OpenAPI 3.1, conservé sans modification pour les tests hors réseau.

- Source : https://spec.openapis.org/oas/3.1/schema/2022-10-07
- Empreinte SHA-256 : `da01ba28852cac0de53893797cb8d1942bc3b05084f526dcc216717dec314ed0`.
- Projet d’origine : OpenAPI Initiative, OpenAPI-Specification.
- Licence Apache 2.0 : copie dans `LICENSE-openapi.txt`.

Le schéma officiel valide la structure OpenAPI. Les schémas de données sont aussi vérifiés séparément avec JSON Schema 2020-12, et toutes leurs références locales sont contrôlées. Cette licence tierce ne définit pas celle du code Gestion-Stock, qui reste à choisir dans DOC-01.
